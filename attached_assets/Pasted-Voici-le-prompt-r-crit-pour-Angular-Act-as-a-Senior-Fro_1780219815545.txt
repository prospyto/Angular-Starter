### 🧱 TYPESCRIPT DATA MODELS (`entities.model.ts`)

Define strict TypeScript interfaces matching the Django REST API UUID-based architecture:

```typescript
export type UUID = string;
export type OrderStatus = 'pending' | 'accepted' | 'pickup' | 'delivered' | 'cancelled';
export type MaterialType = 'wood' | 'leather' | 'fabric';
export type UserRole = 'buyer' | 'seller' | 'driver';

export interface User {
  id: UUID;
  name: string;
  phone: string;
  status: string;
  trust_score: number;
  role: UserRole;
}

export interface Buyer extends User {
  address: string;
  landmarks: string;
  voice_note?: string; // audio file URL
}

export interface Seller extends User {
  store_name: string;
  store_description: string;
  wallet_balance: number;
}

export interface Driver extends User {
  location: { lat: number; lng: number };
  earnings_wallet: number;
  is_available: boolean;
}

export interface Product {
  id: UUID;
  name: string;
  price: number; // in FCFA
  material: MaterialType;
  image_url: string;
  seller_id: UUID;
}

export interface Order {
  id: UUID;
  buyer_id: UUID;
  product_id: UUID;
  driver_id?: UUID;
  status: OrderStatus;
  created_at: string;
}
```

### 🛠️ CORE GLOBAL SERVICES

#### `api.service.ts`

Build a global `ApiService` using Angular's `HttpClient` with:

* All methods returning `Observable<T>` with `catchError` piped via RxJS
* Exponential backoff retry using `retryWhen` or `retry({ delay })` operator
* A `loading$: BehaviorSubject<boolean>` signal exposed globally per call
* Generic typed methods: `get<T>`, `post<T>`, `patch<T>`, `delete<T>`

#### `jwt.interceptor.ts`

A **functional HTTP interceptor** (`HttpInterceptorFn`) that:

* Reads the JWT token from `localStorage` via `AuthService`
* Appends `Authorization: Bearer <token>` to every outgoing request
* On `401` response, clears session and redirects to `/auth`

#### `auth.service.ts`

* Stores JWT + user metadata in `localStorage`
* Exposes `currentUser$: BehaviorSubject<User | null>`
* Provides `login()`, `register()`, `logout()`, `getRole()` methods
* After successful auth, uses Angular `Router` to redirect:
  * `driver` → `/driver`
  * `seller` → `/seller`
  * `buyer` → `/catalog`

#### `toast.service.ts`

* Exposes `show(message: string, type: 'success' | 'error' | 'warning')` method
* Toast auto-dismisses after 3 seconds
* Injected into `AppComponent` and rendered via `toast-banner` shared component

### 🌐 ROUTING (`app.routes.ts`)

```typescript
export const routes: Routes = [
  { path: '', redirectTo: 'auth', pathMatch: 'full' },
  { path: 'auth', loadComponent: () => import('./features/auth/auth.component').then(m => m.AuthComponent) },
  { path: 'catalog', loadComponent: () => import('./features/catalog/catalog.component').then(m => m.CatalogComponent), canActivate: [authGuard] },
  { path: 'seller', loadComponent: () => import('./features/seller/seller-dashboard.component').then(m => m.SellerDashboardComponent), canActivate: [authGuard] },
  { path: 'driver', loadComponent: () => import('./features/driver/driver-dashboard.component').then(m => m.DriverDashboardComponent), canActivate: [authGuard] },
  { path: '**', redirectTo: 'auth' }
];
```

All routes use **lazy loading** via `loadComponent`. The `authGuard` checks role and redirects unauthorized access.

### 🌀 GLOBAL UI REQUIREMENTS (Apply to ALL Screens)

* **Shimmer Skeleton Component:** A reusable `shimmer-skeleton` standalone component rendering animated gray bars (`animate-pulse` Tailwind) matching the shape of the content being loaded. Accept `[lines]` and `[type]` inputs (`'card' | 'list' | 'text'`).
* **Toast Banner Component:** Fixed bottom-center position, `z-50`, slide-up animation. Color-coded: error = soft red bg, success = green bg, warning = orange bg. Auto-dismiss via `setTimeout` in service.
* **No NgModules anywhere.** All components use `standalone: true` with explicit `imports: []` arrays.
* **All forms use `ReactiveFormsModule`** with `FormGroup` / `FormControl` / `Validators`.
* **All HTTP calls use `AsyncPipe`** where possible to avoid manual subscriptions and memory leaks.
* **Tailwind classes only** — no inline `style=""` attributes except for dynamic values like trust score arc length or wallet amount color.
* **Angular Signals** (`signal()`, `computed()`, `effect()`) preferred over `BehaviorSubject` for local component state.
